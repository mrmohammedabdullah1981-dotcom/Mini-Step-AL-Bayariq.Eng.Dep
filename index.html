3. Administrative Control & Security The platform includes a robust back-office module accessible via the "Admin Control" button. Security Protocol Student Privacy: User data is hashed locally and synced to Firebase Firestore using a name-document mapping. Access Control: To prevent unauthorized access to assessments, the platform requires a 4-digit PIN for every session. Purge Capability: Administrators can invoke app.purgeRecords() to clear the database at the end of an academic semester, ensuring a clean slate for new cohorts. 4.
